DIRECT This browser holds the AssemblyAI socket itself. /api/token mints a 60 second streaming token, the page opens wss://streaming.assemblyai.com/v3/ws with no Authorization header (a browser cannot set one, which is the whole reason the token exists), and each committed turn is POSTed to /api/agent. There is no websocket server anywhere, so every number on this page is measured in your browser, not simulated.
